📖 Overview

Every year, thousands of new cybersecurity vulnerabilities (CVEs) are published — but only a tiny percentage are actually exploited in the wild. Security teams often struggle to prioritize which vulnerabilities matter the most.

Traditional scoring systems:

CVSS → rates severity

CVE → provides descriptions

EPSS → predicts likelihood of exploitation

CISA KEV → lists vulnerabilities confirmed to be exploited

However, manually analyzing these datasets is time-consuming and complex.

This project explores whether machine learning can assist in predicting the likelihood of exploitation using these publicly available sources.

🎯 Goal: Not to achieve high accuracy, but to understand the data, discover patterns, and study the challenges in predicting real-world exploits.
